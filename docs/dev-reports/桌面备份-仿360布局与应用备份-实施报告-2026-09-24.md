# 桌面备份-仿360布局与应用备份-实施报告-2026-09-24

## 需求
设置中心「桌面备份」页按 360 的布局方式重做：备份卡以**桌面截图缩略图 + 日期标签**呈网格排列，末位是「添加备份」卡；**鼠标移入备份卡出现「应用备份」按钮**，点击把该备份里的 dock、收纳盒等全部设置/配置恢复生效。

## 实现方案

### 1. 备份实体（持久化，重启不丢）
每个备份是一个目录：`%APPDATA%\DestopTools\backups\<yyyyMMdd_HHmmss>\`
| 文件 | 内容 |
|---|---|
| `DestopTools.ini` | **整份配置快照**：收纳盒（UserBoxes：几何/分类/条目）、Dock、外观、常规、快捷操作、待办等全部落在同一个 INI |
| `thumb.png` | 备份瞬间的桌面截图（480px 宽），作卡片缩略图 |
| `meta.ini` | 备份名（弹框里输入的名称，默认「桌面备份」） |

「添加备份」：弹 BackupDialog 收名称 → sync 落定当前设置 → 复制 INI → **临时隐藏设置中心 280ms** 截屏（避免把设置中心截进缩略图）→ 截完恢复原位。

### 2. 「应用备份」——自动重启生效（关键设计）
程序有**单实例锁（QLocalServer）**，且运行期各窗口会持续向 INI 落盘（saveLayout、折叠态、天气缓存等），所以：
- **不能**在程序还开着时直接覆盖配置（会被运行期落盘盖回去），**也必须等旧实例完全退出后**再覆盖并拉起新实例。
- 编排：点「应用备份」→ 置位 `appexit.h` 的 `g_pendingBackupDir`/`g_restartAfterQuit` → 提示 → `qApp->quit()`；
- `main.cpp` 在事件循环退出、**MainWindow 已析构（全部落盘结束）**之后：`sync()` → 用备份 INI 覆盖现行配置 → `startDetached` 重启程序。
- 净效果：重启后 dock/收纳盒/全部配置精确回到备份时刻，退出路径上没有任何 saveValue 能污染恢复结果。

### 3. 页面 UI（对照 360 截图）
- `QScrollArea`（透明、无边框）+ **2 列网格**：每张备份卡 220×150——缩略图 212×116（8px 圆角裁剪）+ 下方日期标签（如 `20260924`，tooltip 显示备份名与完整时间）。
- **悬停浮层**（半透明黑 45%）：居中「应用备份」按钮（主题色填充）+ 右上角「×」删除（GlassMessageBox 确认后删）。
- 末位「添加备份」卡（+ 号），与 360 一致；备份多时可滚动。
- 全部样式带 **id 选择器**（`backupThumbCard`/`backupCardOverlay`/`backupScroll`…），遵守「无选择器会向子件传播」铁律；样式模板存成员，`applyTheme→restyleBackupCards()` 随主题色/透明度/圆角开关联动。
- 缩略图 DPR 安全：截图统一按物理像素（DPR=1）落盘，卡片按 `devicePixelRatioF()` 渲染，高 DPI 不糊不偏。

### 4. 附带处理
- BackupDialog 的「同步备份设置中心设置」复选框：全量备份后必然包含设置中心设置，复选框失去语义 → **隐藏**（名称输入/确认流程不变）。

## 改动文件
