# 桌面备份 - 卡片不刷新 / 应用备份不还原 修复报告

## 问题 1：添加备份后卡片不显示，须重开关备份页才出现
**根因**：`createBackupNow` 已调用 `rebuildBackupCards()` 重建网格，但之前用了 `::ShowWindow(SW_HIDE/SW_SHOW)` 临时隐藏设置中心窗口，QScrollArea 的视口缓存没被强制刷新——新卡片已加入布局却不重绘。

**修复**（`settingcenterdialog.cpp` `createBackupNow` 末尾）：rebuild 后显式
```cpp
m_backupGrid->invalidate(); m_backupGrid->activate();
m_backupGridHost->update();
m_backupScroll->viewport()->update();
QApplication::processEvents();
```
新卡片立即可见。

## 问题 2：应用备份没还原（解散的分类图标仍在 dock）
**根因**：还原编排依赖 `main()` 在 `a.exec()` 返回后"覆盖配置 + 重启"，但两道关卡让它根本跑不到——
1. 设置中心是 `exec()` 拉起的**嵌套模态**，`qApp->quit()` 只退出最内层（对话框）循环，MainWindow 的主事件循环仍在跑 → `a.exec()` 不返回 → 还原块（main.cpp）不执行。
2. 更致命：旧实例的 `QLocalServer`（单例锁）在 `startDetached` 拉起新实例时**仍在监听** → 新实例 `connectToServer` 成功 → 误判"程序已在运行" → 直接退出，重启从未发生。

**修复**：
- `applyBackupNow`（`settingcenterdialog.cpp`）：`qApp->quit()` 改为先 `accept()` 关掉对话框，再 `QTimer::singleShot(0, qApp, &QApplication::quit)` 在**主事件循环**上下文二次 quit，确保 `a.exec()` 真正返回（模态本身未改，符合"保留模态"要求）。
- `main.cpp` 在 `QProcess::startDetached` 前加 `QLocalServer::removeServer(singleInstanceName)` + `localServer->close()`，释放命名管道，新实例才能顺利 listen 并启动。

> 还原逻辑本身正确（整份 `DestopTools.ini` 覆盖，盒子/分类/图标从属都在里面）——之前的"不还原"是编排跑不到，不是还原算错。
