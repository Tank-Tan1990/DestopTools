## 一、现象（用户报）

1. 分类标签栏（快捷方式 / 目录 / 文档 / …）那一条，原来有一圈带背景的圆角外线框，现在没了。
2. 每个分类对应的**图标区域**同样有一圈外线框，也没了。

---

## 二、先量证据（不是目测）

拿两张实拍截图做逐像素对比（同一盒子，宽 917 / 918px）：

| 图标区左/右竖直长线 | 有 | **完全没有** |

**关键对位**：那两条横线的间距 **34px**，与 `m_categoryBar->setFixedHeight(34)` 一字不差；
线色 `(16,59,44)` 在以 `accent=#10b981` 反算后 alpha = (59-23)/162 = **0.22**，
与 `panelStyle()` 里 `border: 1px solid rgba(34,211,238,0.22)` 完全一致。

⇒ 这两圈线**根本不是为分类栏/图标区画的**，而是卡片样式表里那条 border。

---

## 三、根因

`IconGridWindow` 的 `card` 用的是 **无选择器**样式串（`Theme::panelStyle()` 这类）：

```cpp
card->setStyleSheet(Theme::boxChrome(Theme::panelStyle()));
// 展开后 = "background-color: rgba(17,26,46,1.0);
//            border: 1px solid rgba(34,211,238,0.22);
//            border-radius: 16px;"
```

Qt 的样式表规则：**无选择器的声明会套到该 widget 的每一个后代上**。于是：

- `m_categoryBar`（裸 `QWidget`，自己的样式只有 `background: transparent;`）
  → 白捡到 `border: 1px solid 0.22` + `border-radius: 16px` → 显出一圈 34px 高的圆角线框
- `m_gridScroll->viewport()`（`QScrollArea` 的 viewport 就是普通 `QWidget`）
  → 同样白捡到一份 → 显出图标区那圈线框
- （`m_gridScroll` 样式串里那句 `QScrollArea::viewport { border: none; }` **不是 Qt 认得的子控件选择器**，
  一直处于"写了但不生效"的状态 —— 也正因如此，图标区的框才可能来自传播。）

而「盒子显示边框」开关关闭时，`boxChrome()` 会把 `border: 1px solid …;` 整条从 card 串里**删掉**：

```cpp
inline QString boxChrome(QString s) {
    s = applyTokens(s);
    if (!ThemeManager::instance()->boxBorderEnabled()) {
        static const QRegularExpression reBorder("border\\s*:\\s*1px\\s+solid\\s+[^;]*;");
        s.remove(reBorder);          // ← 这一删，所有"白捡"到它的子控件同时丢框
    }
    return s;
}
```

⇒ **一个只该管"盒子最外层那一圈"的开关，连带把两个内部框一起关掉了。**

## 四、修法：把两个内部框显式化，与 boxBorder 解耦

口径（按用户要求）：**这两圈线属于盒子内部结构，与「收纳盒 / 桌面助手界面外」的 boxBorder 无关，必须常驻。**

`theme.h` 新增两个**带选择器**的样式（带选择器 ⇒ 只匹配自身、不再向子控件传播）：

```cpp
inline QString categoryStripStyle() {
    return applyTokens(QStringLiteral(
        "QWidget#iconGridCategoryBar {"
        " background: transparent;"
        " border: 1px solid rgba(34,211,238,0.22);"
        " border-radius: 16px;"
        "}"
    ));
}

inline QString iconAreaStyle() {
    return applyTokens(QStringLiteral(
        "QWidget#iconGridViewport {"
        " background: transparent;"
        " border: 1px solid rgba(34,211,238,0.22);"
        " border-radius: 16px;"
        "}"
    ));
}
```

`icongridwindow.cpp` 三处接上：

| 位置 | 改动 |
|---|---|
| 构造期 `m_categoryBar` | 加 `setObjectName("iconGridCategoryBar")`，样式由裸 `background: transparent;` → `Theme::categoryStripStyle()` |
| 构造期 `m_gridScroll` 之后 | `viewport()->setObjectName("iconGridViewport")` + `setStyleSheet(Theme::iconAreaStyle())` |
| `applyTheme()` 内 | 两处改为重设上述两个样式（主题色 / 透明度 / 「盒子使用圆角」变化时自动重刷） |

**为什么这样就不会再被开关牵连**：这两个样式不经过 `boxChrome()`，
而 boxChrome 只作用于 `card` / 窗口自身那条串；两个内部框的规则带选择器，也不再从 card 继承任何东西。

**视觉口径保持不变**：颜色仍是 `accent @ 0.22`、圆角仍是 16px（与卡片同值），
只是把"靠继承碰巧得到"改成"显式写上"。勾选「盒子使用圆角」时它俩一起变圆，取消时一起变方。

**防回归注释**：两处调用点都写了 `🚨 不要改回裸 background: transparent;`，说明改回即退回传播机制。
