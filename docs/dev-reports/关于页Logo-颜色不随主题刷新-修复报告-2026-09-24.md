# 「关于我们」页 Logo 颜色不随主题色刷新 —— 修复报告

日期：2026-09-24 03:44
产物：`DestopTools/release/DestopTools.exe` = 1,355,264 B @ 2026-09-24 03:43:58（`NMAKE_EXIT=0`）

## 一、现象

设置中心 →「关于我们」页，红框内的显示器 Logo 是**金色**，而**同一个窗口**里侧边栏选中项「关于我们」的底色、外框描边都已经是**青绿**。

当前持久化的主题色：`%APPDATA%/DestopTools/DestopTools.ini` →

```ini
[Appearance]
colorIndex=10
accent=#14b8a6
```

`#14B8A6` 是青绿。**同一窗口内两处颜色不一致**，说明不是「主题色错了」，而是「有一处没跟着刷新」。

## 二、根因

`settingcenterdialog.cpp` 的 `createAboutLogo()` 用 `QPainter` 把颜色**画进 QPixmap**：

| 元素 | 取色 |
| --- | --- |
| 显示器外框描边 | `accentColor()` α120 |
| 屏幕内左块「谭」字 | `accentColor()` |
| 支架 / 底座 | `accentColor()` α60 |
| 右块「征」字 | `accentColor().lighter(115)` |

**位图的颜色是「烤」进像素的，不会自己去读 ThemeManager** —— 这跟 QSS 完全不同：QSS 每次 `applyTheme()` 重新拼串，天然跟着主题色走。

而它只在 `createAboutPage()` 里生成一次；`SettingCenterDialog` 又是 mainwindow.cpp 里三处 `SettingCenterDialog dlg(...)` 的**栈上局部对象**（每次打开才 new）。于是：

1. 打开设置中心那一刻的主题色被**定格**在 Logo 位图里（用户当时是金色 → 应该是此前点过色板 index 7 的 `#FBBF24`，`palette` 里最后一格 `#550000` 也说明最近动过色板）；
2. 在对话框里改主题色 → `ThemeManager::themeChanged` → `applyTheme()` → QSS 全量重刷，侧边、边框、Dock、各处控件全变青绿；
3. **唯独关于页 Logo 还是打开那一刻的金色** —— 位图没人重建。

## 三、修复

`SettingCenterDialog` 新增一个「重绘位图」的职责：

**`settingcenterdialog.h`**

```cpp
    QWidget* createAboutPage();
    void updateAboutLogo();     // 关于页 Logo 重绘（主题色联动）
    ...
    QLabel* m_aboutLogo = nullptr;
```

**`settingcenterdialog.cpp`**

```cpp
// 构造时 + applyTheme() 各调一次
void SettingCenterDialog::updateAboutLogo() {
    if (!m_aboutLogo) return;          // 构造早期 applyTheme() 先于 createAboutPage() 时安全跳过
    qreal dpr = 1.0;
    if (QScreen* sc = this->screen()) dpr = sc->devicePixelRatio();
    if (dpr < 1.0) dpr = 1.0;
    QPixmap pm = createAboutLogo(qRound(160 * dpr), qRound(120 * dpr));
    pm.setDevicePixelRatio(dpr);        // 位图分辨率按 DPR 放大，逻辑尺寸不变
    m_aboutLogo->setPixmap(pm);
    m_aboutLogo->setFixedSize(160, 120);
}
```

- `createAboutPage()`：只建空 label、登记 `m_aboutLogo`，末尾调 `updateAboutLogo()`；
- `applyTheme()`：在 `restyleBackupCards()` 之后补一次 `updateAboutLogo()`。

顺带把位图按屏幕 DPR 超采样再 `setDevicePixelRatio`，逻辑尺寸恒 `160×120`（布局不变），125%/150% 缩放的屏幕上不再发虚。

## 四、关于「用什么颜色」

用户口径：**「颜色跟着主题变化也行，实在不行改回之前的颜色」** → 取首选，即 **Logo 恒等于当前主题色**（与设计原意一致，原注释就写着「主题色弱描边玻璃」「青色弱描边」）。

- 当前主题色 `#14B8A6` → 重启后 Logo 为**青绿**；
- 想把 Logo 调成别的颜色，直接在外观设置里改主题色即可，Logo 会**即时**跟随（本次修复的效果）；
- 若日后决定让 Logo **固定**成程序图标那套品牌色（`appicon.ico` 用的翡翠绿 `#10B981`），改一处即可：把 `createAboutLogo()` 里 3 处 `ThemeManager::instance()->accentColor()` 换成固定 `QColor(QStringLiteral("#10B981"))`。

> 注：exe 的程序图标（任务栏 / 资源管理器）是**编译期资源**（`appicon.rc` → `appicon.ico`），天然不随主题色变，这是正常的；会随主题色变的只有页内这个用 QPainter 画的 Logo。
