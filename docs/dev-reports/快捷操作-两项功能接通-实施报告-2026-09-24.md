## 一、需求
设置中心 →「快捷操作」→「快捷功能」里的两个复选**此前只在设置中心读写、全项目零消费端**（勾不勾都没反应）：
1. 双击桌面空白处隐藏桌面图标
2. 在桌面空白处绘制创建收纳盒

两个键早已落盘：`QuickActions/hideIconsOnDoubleClick`、`QuickActions/drawBoxOnBlank`（默认 true）。

## 二、实现

### ① 双击桌面空白处 → 隐藏 / 显示桌面图标
- **为什么必须自己判双击**：`WH_MOUSE_LL` 只送 `WM_LBUTTONDOWN/WM_LBUTTONUP`，`WM_LBUTTONDBLCLK` 是**窗口消息**，永远不经低级钩子 → 系统不会替我们识别。判定用系统参数：`GetDoubleClickTime()` + `SM_CXDOUBLECLK/SM_CYDOUBLECLK` 的一半作位置容差（与 Explorer 同口径）。
- **只在"空白处"计数**：判定点在钩子通道 `onBlankPressFromHook`，点在图标可视区时先把计数清零 → **双击图标仍然是"打开文件"**，绝不会连带隐藏桌面图标。
- 命中后：`m_suppressRubber = true` 让这一击不再起框（Qt / 钩子两条通道都拦），清掉选中，然后切换隐藏态。
- 隐藏态＝把全部 Dock 图标按钮 `setVisible(false)`（即"桌面上的图标"）。**只在内存里**：重启即恢复显示，不会让用户下次开机困惑。
- 🚨 隐藏态必须在 `layoutButtons()` 末尾重套（`applyDesktopIconsHiddenState()`）：否则任何一次桌面刷新 / 按钮重建（文件增删、整理、盒↔Dock 拖拽、切模式）都会把隐藏态冲掉。

### ② 桌面空白处拉框 → 按框新建收纳盒
- **复用 Dock 已有的橡皮筋**（`beginRubber/updateRubber/endRubber` + 16ms 轮询，不依赖 Qt 事件路由 —— Dock 是 `WS_EX_NOACTIVATE` 的底层窗口）。
- `beginRubber` 里确定本次框的语义：`m_rubberCreatesBox = (开关开 && 未按 Ctrl)`。
  - 建盒模式：拖动中**不选中图标**（框内图标马上要被收走，高亮只会误导，也会留下悬垂选中）。
  - **Ctrl 拉框恒为框选多选** —— 多选（F2 / Delete / 整组拖动）这条既有能力留一个不必改配置的逃生口；Ctrl 本来就是"加选"修饰键，语义自洽。
- 松手（`endRubber`）：框小于 48×36 逻辑像素视为"点了一下"（否则每次单击桌面都会冒出一个空盒）；否则收集框内图标（`hitsVisualRect()` 与框**相交**即算，跳过 `"::"` 系统虚拟项）→ `emit boxRegionDrawn(globalRect, paths, names)`。
- 自绘：建盒模式改用当前主题强调色（`Theme::accentCyan()`）+ 框内提示 **「松开即创建收纳盒」**，与"框选图标"的淡蓝框一眼可辨。
- `MainWindow::createBoxFromDockRegion()`：按框建盒（名称 `收纳盒N`，取未被占用的最小序号，可随后右键改名；几何＝画出的框，夹进屏幕可用区且不小于 IconGridWindow 的最小尺寸 480×176）；框内图标走**既有**的 `scheduleDockItemsIntoBox`（＝"从 Dock 拖图标进收纳盒"同一条通道：只写本盒数据 + 重算 Dock 隐藏集合 + 落盘）→ 那批图标立刻从桌面消失、只出现在新盒子里。

### ③ 设置项热更新（两段式，遵循项目铁律）
- 消费端是常驻的 Dock：**构造期读一次缓存**（`m_quickHideIconsOnDblClick` / `m_quickDrawBoxOnBlank`）+ `connect(ThemeManager::instance(), &settingChanged, …)` 按 key 热更新。
- 🚨 钩子路径禁做文件 I/O：绝不能在鼠标钩子回调里读设置（＝读 INI），所以必须缓存。
- `settingcenterdialog::saveSettings()` 补两句 `notifySettingChanged("QuickActions/…")` —— 不广播就得重启才生效。

## 四、请实测
1. **双击桌面空白**：桌面图标全部消失（再双击一次全部回来）；双击图标仍是打开文件；隐藏状态下动一下桌面文件（增删/改名）不应让图标自己回来。
2. **拉框建盒**：桌面空白按住左键拖出一个框 → 框是青色并显示「松开即创建收纳盒」→ 松手后该位置出现新收纳盒，框内图标被收进去、从桌面消失；空框（没框到图标）也会建一个空盒。
3. **Ctrl + 拉框**：仍然是原来的框选多选（可接着 F2 重命名 / Delete 删除 / 整组拖动）。
4. 把两个开关**取消勾选**后立即生效（无需重启）：双击空白不再隐藏图标；拉框回到"框选多选"。

> 行为变更提示：开关②默认是**勾选**的，所以桌面空白处"拖一个框"从"框选图标"变成了"建收纳盒"。需要临时框选图标时按住 **Ctrl** 拖即可；若更希望默认是框选，把该复选取消勾选即可（拉框建盒随之关闭）。
