## 一、需求

1. 待办行首的提醒红点 → **换成喇叭图标**，并且要**一闪一闪**的动画效果。
2. **点过提醒弹框的 OK 按钮之后**，才清除这个标记。

## 二、语义变更：提醒不再「到期即自动清除」

原来是 `TodoStore::checkReminders()` 一到点就 `clearReminder()` + 弹框 —— 标记跟着立刻消失，用户"没看清就没了"。

现在：

```cpp
void TodoStore::checkReminders() {
    ...
    for (const TodoItem& it : m_items) {
        if (it.reminder.isValid() && it.reminder <= now && !it.text.isEmpty()
            && !m_firedIds.contains(it.id)) { ... }
    }
    ...
    m_firedIds.insert(dueIds[i]);      // ← 只记「已弹过」，不 clearReminder
    emit reminderDue(dueIds[i], dueTexts[i]);
}
```

- **提醒时间与行首标记都保留**，直到用户确认；
- 新增内存集合 `QSet<QString> m_firedIds` **防重复弹框**（扫描是 15 秒一次，不清除提醒的话会反复弹）；
- 集合**不持久化**：重启后清空 → 未确认的提醒会再提醒一次（用户没处理完，理应继续提醒）；
- 进出场维护：`checkReminders` 插入；`acknowledgeReminder` / `setReminder`（重设＝重新计时）/ `clearReminder` / `remove` / `removeDone` 里移除。

新增接口：

```cpp
void TodoStore::acknowledgeReminder(const QString& id) {
    m_firedIds.remove(id);
    clearReminder(id);          // save + itemsChanged → 面板重建时不再画喇叭
}
```

## 三、面板侧：只有点 OK 才确认

```cpp
const int r = GlassMessageBox::warning(this, QStringLiteral("待办提醒"), text);
stopReminderSound();
if (r == QDialog::Accepted) TodoStore::instance().acknowledgeReminder(id);
```

已核对 `glassmessagebox.cpp`：OK 按钮是 `connect(okBtn, &QPushButton::clicked, this, &QDialog::accept)`（且 `setDefault(true)`，回车同效）→ `exec()` 返回 `QDialog::Accepted`；**Esc / [X] 走 `reject()` 返回 0 → 不清除**。所以"没看清就被关掉"不会把提醒弄丢，标记继续闪，重启后还会再提醒一次。

## 四、标记：红点 → 闪烁的喇叭

```cpp
if (it.reminder.isValid()) {
    auto* bell = new QLabel(row);
    bell->setFixedSize(14, 14);
    const qreal dpr = devicePixelRatioF();
    const int px = qMax(14, qRound(14 * dpr));
    QPixmap pm = Theme::icon(QStringLiteral("speaker")).pixmap(QSize(px, px));
    pm = Theme::recolorPixmap(pm, QColor(QStringLiteral("#FA5151")));   // 提醒红
    pm.setDevicePixelRatio(dpr);
    bell->setPixmap(pm);
    bell->setToolTip(QStringLiteral("提醒：%1").arg(it.reminder.toString(QStringLiteral("MM-dd hh:mm"))));

    auto* eff = new QGraphicsOpacityEffect(bell);
    eff->setOpacity(1.0);
    bell->setGraphicsEffect(eff);
    auto* anim = new QPropertyAnimation(eff, "opacity", bell);
    anim->setDuration(900);
    anim->setKeyValueAt(0.0, 1.0);
    anim->setKeyValueAt(0.5, 0.15);
    anim->setKeyValueAt(1.0, 1.0);
    anim->setLoopCount(-1);
    anim->start();
    lay->addWidget(bell, 0, Qt::AlignVCenter);
}
```

- 位置仍在**行的最前方**；14px 线性图标，与右侧 12px **方形**优先级圆点区分；
- 颜色 `#FA5151` 固定，不随主题色变（它是状态标记）；
- effect / animation 都以该行为父 → 行重建即回收，不留野动画；模态弹框有自己的事件循环，闪烁照常进行。

## 五、踩坑

🚨 **Qt 5.14 的 `QIcon` 没有带 `devicePixelRatio` 的 `pixmap()` 重载**（Qt 6 才有）。5.14 只有：

```cpp
QPixmap pixmap(const QSize &size, Mode mode = Normal, State state = Off) const;
QPixmap pixmap(QWindow *window, const QSize &size, Mode, State) const;
```

写 `icon.pixmap(QSize(14,14), dpr)` 直接报 **`error C2665: "QIcon::pixmap": 没有重载函数可以转换所有参数类型`**。

正解：**自己按 DPR 算需要的设备像素**，再让 `QIcon` 去挑最合适的切图（本项目每图标都有 24 / 48 两档），最后 `setDevicePixelRatio(dpr)` 贴回去 —— 屏上仍是 14×14 逻辑像素，缩放屏不发虚。
