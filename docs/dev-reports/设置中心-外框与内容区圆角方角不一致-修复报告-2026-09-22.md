## 一、现象（先量后改）

对截图做了逐像素测量（`clipboard-2026-09-21T19-14-33-060Z-*.png`，859×667，对话框占 x 26..845 / y 30..649 = **820×620 1:1**），得到两条互相打架的事实：

| 部位 | 实测 | 推断 |
|---|---|---|
| 窗口外框线 | 被切角，弧线出现 | **被 15px 圆角遮罩裁过** |
| 侧栏（x=28..207） | 1px 线，颜色 (16,59,44)，**四角为直角** | 线框是**方角** |
| 内容区（x=208..843） | 同一颜色，四角**缺口**（左线 85..580、上线 219..832） | 方角线框**被圆角遮罩切掉四角** |
| 标题栏 / 底栏 | 无圆角 | 半径已被归零 |

反算颜色：底色 (16,23,21)、当前主题色为青绿时，`rgba(accent, a)` 合成后 G = 23+162a → 实测 G=59 ⇒ **a ≈ 0.22**，正是 `m_rootFrame` 那条 `ROOT_BORDER_ALPHA=0.22` 的描边。

**结论：线框已经全部被「盒子使用圆角」开关压成方角（applyTokens 生效），但窗口/内容区的遮罩仍是写死的 15px 圆角 —— 于是遮罩把方角线框的四角切出缺口**。用户看到的「外框像圆角、内容区像方角豁口」就是这两态打架的产物。

## 二、根因（三条，全部已修）

### ① 遮罩半径写死 15px，不跟随开关（主因）
`updateRoundedMask()` / `updateStackMask()` / `paintEvent()` 里的 `15` 是常量。而「盒子使用圆角」的归零只发生在 **QSS 串**里（`Theme::applyTokens` 的正则），**遮罩（setMask/QRegion）与自绘圆角根本不过 QSS** → 必然错位。

### ② 侧栏与内容区各继承了一圈 0.22 线框（解释了"内容区为什么有线框"）
`m_rootFrame` 的样式串是 `QFrame { … border: 1px solid rgba(…,0.22); border-radius: 15px; }`（选择器是**裸类型 `QFrame`**）。
`QListWidget`（→QAbstractScrollArea→**QFrame**）与 `QStackedWidget`（→**QFrame**）都是 QFrame 子类 ⇒ 该规则**继承落到侧栏和内容区**上，各画一圈 1px 描边。
几何完全吻合：侧栏 = x 28..207（180 宽）、内容区 = x 208..843，正是 body 布局里两个子件的实际矩形。
半径同被压成 0 ⇒ 这两圈是**直角**线框 —— 也正是「内容区方角」的来源。

### ③ 标题栏/底栏圆角与外框**不同心**（用户猜的"边距"就在这里，但不是元凶）
子件距窗口外沿 **2px** = 1px QSS 描边（Qt 会把 QSS 边框算进 layout 的 frame 内缩）+ `rootFrameLayout` 显式 `setContentsMargins(1,1,1,1)` 的 1px。
标题栏/底栏却仍用 15px 半径 ⇒ 与 15px 外框圆角不同心，圆角处多出 2~3px 月牙缝（露出外框底色）。方角态看不出来，圆角态会很明显。

## 三、改动清单

### `theme.h`（+16 行）
新增 **C++ 侧取半径的唯一出口**（紧接 `boxChrome()` 之后）：

```cpp
// applyTokens 只压得动 QSS 里的 border-radius；窗口遮罩（setMask/QRegion）与自绘圆角
// （paintEvent 的 drawRoundedRect）根本不走 QSS —— 它们写死 15px 时两态就会打架。
// ⇒ 凡 C++ 侧要画圆角或裁圆角，一律用本函数取半径，禁止再写死数字。
inline int radiusPx(int base) {
    return ThemeManager::instance()->boxRoundedEnabled() ? base : 0;
}
```

### `settingcenterdialog.cpp`（4 处）
| 位置 | 改动 |
|---|---|
| `updateRoundedMask()` | `r = Theme::radiusPx(15)`；`clearMask()` 后 **r<=0 直接 return**（方角态 = 原生矩形窗口，不裁） |
| `updateStackMask()` | 同上；`r<=0` 时 `m_stack->clearMask()`（内容区方角线框不再被切角） |
| `paintEvent()` | `fillRadius = Theme::radiusPx(15)`（0 时 `drawRoundedRect` 等价直角矩形） |
| `applyTheme()` | 开头补一次 `updateRoundedMask()` —— 开关变化走 `themeChanged → 本窗 onStyle`，只重刷样式不重算 mask 的话要等下次 showEvent/resizeEvent 才生效（表现为"要重启"） |
| 标题栏样式 | `border-top-left/right-radius: 15px → 13px`（15 − 1px 描边 − 1px 内边距 = **与外框同心**） |
| 底栏样式（2 处） | `border-bottom-left/right-radius: 15px → 13px`（同上） |

**没有做的事**：没有把 `rootFrameLayout` 的 1px 内边距改掉。原因是 Qt 已按描边自动内缩 1px，把那 1px 去掉会把侧栏/内容区整体外移，侧栏描边会与外框描边**紧贴成 2px 粗线**，反而更糟；改圆心（半径 13）即可消除月牙缝且不动任何布局。
