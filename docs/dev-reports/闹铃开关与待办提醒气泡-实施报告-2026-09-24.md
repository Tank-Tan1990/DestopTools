**消费端**（`sidepanelwidget.cpp` 的 `reminderDue` 槽）：

```cpp
const bool soundEnabled = sm.loadValue(QStringLiteral("Appearance/remindSoundEnabled"), true).toBool();
if (soundEnabled) startReminderSound(remindSound);   // 弹框显示期间循环播放
GlassMessageBox::warning(this, QStringLiteral("待办提醒"), text);
stopReminderSound();
```

该槽**每次提醒到期都实时读盘**，所以天然拿的是最新值：改完开关立刻按新值走，既不依赖广播、也不必重启。静音时**提醒弹框照常弹出**，只是不出声。

## 三、需求②：行首提醒气泡

`sidepanelwidget.cpp::buildTodoRow()` 在 `lay->addWidget(circle)` **之前**插入：

```cpp
if (it.reminder.isValid()) {
    auto* bubble = new QLabel(row);
    bubble->setFixedSize(8, 8);
    bubble->setStyleSheet("background: #FA5151; border-radius: 4px; border: none;");
    bubble->setToolTip(QStringLiteral("提醒：%1").arg(it.reminder.toString("MM-dd hh:mm")));
    lay->addWidget(bubble, 0, Qt::AlignVCenter);
}
```

- **位置**：行的最前方（优先级圆点之前），符合「选项的最前方」；
- **观感**：8×8 正圆 + 微信红 `#FA5151`。颜色**固定不随主题色变** —— 它是「有提醒」的状态标记，不是装饰，换主题色时不该跟着变；
- **与右侧圆点区分**：右侧优先级圆点是 12×12 **方形圆角**、可取红/黄/绿；气泡是 8×8 **正圆**且位置最靠左，两者不会混；
- **消失时机**：提醒到期后 `TodoStore::checkReminders()` 会 `clearReminder()` → `itemsChanged` → 重建列表 → 气泡自动消失。

> 本次**只改了助手面板**（`sidepanelwidget.cpp`）；「事项清单」窗（`todolistwindow.cpp::buildRow`）结构同源，未动 —— 需要两边一致的话说一声即可补上。
