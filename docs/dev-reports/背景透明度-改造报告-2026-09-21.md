# 透明度改造 —— 只调「背景」，不调「圆角线框」（2026-09-21）

> 需求原文：**透明度调节的是所有 UI 界面、弹框、菜单弹框等所有程序界面的背景；所有的圆角线框透明度不调整。**

## 一、结论先说

| | 改前 | 改后 |
|---|---|---|
| 机制 | `setWindowOpacity(α)` —— **整窗**不透明度 | α 进**背景色**（QSS rgba 的第 4 位） |
| 圆角线框 | 跟背景一起变淡（α=0.15 时几乎看不见） | **恒定设计值**（0.20 / 0.22 / 0.28…） |
| 文字 / 图标 | 一起被淡化 | 保持原样（清晰） |
| 覆盖范围 | 只覆盖"登记过的窗口" | 全局 QSS + 各窗口样式 + **QMenu / 下拉框弹层 / 日历弹层** |
| 拖动代价 | 每次下发要走 15 个窗口的整窗 opacity | 松手才下发一次（滑块 `setTracking(false)`），期间摘低级钩子 |

## 二、为什么是"一处接缝"，而不是改 20 个文件

先把事实摸清了：全项目**所有背景色字面量只有两种** —— `rgba(17,26,46,1.0)`（窗/面板底）与 `rgba(11,16,33,1.0)`（更深的底），
而且**每一处都包在 `Theme::applyTokens(...)` 里**（已用脚本逐行核对：56 处全部命中，无漏网）。
`applyTokens()` 把这两个字面量统一替换成 `windowBgString(1.0)` / `panelBgString(1.0)`。

所以只要在这两个函数里把 alpha 换成"背景专用通道"，**全局样式表、每个窗口的样式串、菜单/弹框样式一次性全部跟随**，
不需要去动那 56 处字面量，也不需要考虑哪个窗口漏了。

### 核心改动（`theme.h`）

```cpp
// ① 线框 / 文字 / 填充：固定不透明度，永不随滑块变化。
inline qreal alphaF(qreal base)   { return qBound(0.0, base, 1.0); }

// ② 背景色专用：base × 全局界面背景透明度（100 → ×1.0，0 → ×0.15 保底）。
inline qreal bgAlphaF(qreal base) { return qBound(0.0, base * ThemeManager::instance()->effectiveOpacity(), 1.0); }
```

`windowBgString` / `panelBgString` / `deepBgString` 与各 glass 取色函数（`windowGlass` / `dialogGlass` /
`screenshotPanelBg` / `windowBgDeep` …）改走 ②；**所有 border / divider / hover 填充 / 文字灰阶仍走 ①**。
已用脚本反查确认：**没有任何一条 `border: ...` 使用背景色 helper**。

## 三、逐项改动

| 文件 | 改动 |
|---|---|
| `theme.h` | 新增 `bgAlphaF` / `applyBgAlpha`；三个 `*BgString` 与 6 个 glass 取色改走背景通道；`globalStyleSheet()` **缓存键加入透明度**（否则改完透明度会把旧串原样返回，main.cpp 字符串比对"命中未变化"→ 永不生效） |
| `thememanager.h/.cpp` | **删除 `onOpacity` 通道**（`registerThemeTarget` 由 3 参改 2 参）；透明度变化改为与主题色同样走 `onStyle`；`setTransparency` 增一行诊断（默认关闭，非阻塞） |
| `settingcenterdialog.cpp` | ① 自绘 `paintEvent` 的圆角底 `setAlpha(255)` → `applyBgAlpha(...)`：**改前这一个窗口永远不跟随透明度**，而滑块就在本窗里，最容易被看见；② 下拉弹层硬编码 `rgb(73,65,68)` → `rgba(17,26,46,1.0)`（3 处样式块共 9 例）；③ 去掉 `setWindowOpacity`，显式 `setWindowOpacity(1.0)` 固化语义 |
| `shutdowntimerwindow.cpp` | ① 日历弹层样式**此前没走 `applyTokens`** → 既不跟随主题色也不跟随透明度，已抽出 `calendarStyle()` 并纳入；② 长期窗的 `onStyle` 从"只刷卡片/标题栏"补全为"下拉框 + 单选指示器 + 日期 + 日历"（否则改完透明度再打开本窗，这些底会停在旧值） |
| `feedbackdialog.cpp` | 下拉弹层 `rgb(73,65,68)` → `rgba(17,26,46,1.0)` |
| `icongridwindow.cpp` | 去掉 `setWindowOpacity`（2 处），登记简化为单通道 |
| `assistantwindow / filesearchwidget / todolistwindow / wallpaperwindow` | 去掉 `setWindowOpacity`，只保留 `onStyle` |
| `backupdialog / glassinputdialog / glassmessagebox / updatedialog / feedbackdialog` | 按需创建的模态框：去掉 `setWindowOpacity` 与登记（样式在 `setupUi()` 里就地生成，每次弹出天然是最新值） |
| `mainwindow.cpp / settingsmanager.cpp` | 落盘的盒子默认色由 `Theme::panelBg()`（现在带透明度）改为 `Theme::panelBgColor()`（alpha 恒 255）——否则会把"当时的透明度"烘进配置 |

## 五、已知取舍（如需再谈，请指定）

1. **文字不再跟着变淡**。说明：需求只点了"背景"与"线框"，文字按"背景之外"处理 → 低透明度下是"清晰文字浮在很透的底上"。
   若想连文字一起淡化，那就是回到整窗不透明度（线框也会跟着淡）——两者不可兼得，除非给文字单独做一层。
2. **档位下限仍是 0.15**，语义与改前一致（改前 `setWindowOpacity(0.15)` 得到的背景 alpha 也是 0.15）。
3. **嵌套同色底会叠加**（窗底 + 卡片底），这是改造前的既有结构，观感与历史版本一致，未改动。
4. **原生 Shell 右键菜单**（系统绘制）不受本设置影响，也无法影响。
