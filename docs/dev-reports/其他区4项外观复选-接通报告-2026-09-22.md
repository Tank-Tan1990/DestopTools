## ② 盒子使用圆角 `Appearance/boxRound`

**口径**：勾选 → 所有界面、弹框、弹框菜单等**所有使用的线框**显示圆角矩形；
取消 → 全部显示方角矩形。

**接缝**：在 `Theme::applyTokens()` **尾部**统一把所有 `border-radius` 归零。

这是唯一正确的位置：全项目所有 `Theme::*Style()` 与 `buildGlobalStyleSheet()` 的返回值
**都必经 `applyTokens()`** → 一处改动即覆盖 面板 / 对话框 / 弹出菜单 / 输入框 / 按钮 / 滚动条 /
复选框指示符 / 标签页 / 进度条 …… 逐个控件去改既改不全，也必然随新增控件再次漏掉。

```cpp
// 五个属性一次匹配，否则标题栏（用 border-top-left/right-radius）会残留圆角
if (!tm->boxRoundedEnabled()) {
    static const QRegularExpression reRadius(QStringLiteral(
        "(border-radius|border-top-left-radius|border-top-right-radius|"
        "border-bottom-left-radius|border-bottom-right-radius)\\s*:\\s*[^;}]+"));
    s.replace(reRadius, QStringLiteral("\\1: 0px"));
}
```

- **语义刻意做成「勾选 = 不动原有值」**：各控件圆角本就不同（面板 16 / 按钮 10 / 菜单 12 / 指示符 3…），
  勾选时保留这些既有值，取消时统一压成 0 —— 两态之间只差"圆角有无"，不会顺手改动任何已定稿的视觉层次。
- 终止符是 `[^;}]+`（**不是** `[^;]+`）：属性值后面偶尔会直接跟 `}` 而没有分号，只用分号收尾的话
  会一路吃到串尾，把后面的 `}` 一起替换掉 —— 那就不再是"改圆角"而是"改坏样式"。
- `FenceBox`（全屏盒子，不走 `applyTokens`，是自定义拼接）单独用 `.arg`/拼接处理，同样跟随本开关。
- **🚨 `globalStyleSheet()` 的缓存键补入 `boxRound`**：它是样式串内容的直接输入，漏进缓存键的话，
  勾/取消时缓存会把旧串原样吐回，`main.cpp` 的字符串比对判定"未变化"，本项将**只在重启后才生效**。

## ③ 在快捷方式图标上显示箭头 `Appearance/shortcutArrow`

**口径**：勾选 → dock / 收纳盒内所有快捷方式显示箭头；取消 → 所有快捷方式都不显示。

**接缝**：复用**既有**的 `arrowScale` 通道，新增 `Theme::shortcutArrowOverlayScale(double)`
（开关关闭时返回 `0.0`），**不新增 bool 参数**。理由：

- `DesktopScanner::loadIcon()` 的进程内图标缓存键已经含 `arrowScale`（`parsename|effSize|arrowScale`），
  用 0 表示"不要箭头"后，开关两态**各自命中各自的缓存条目**，来回切换能直接复用、也不会串味；
- `DesktopScanner::composeShortcutOverlay()` 增加早退 `arrowScale <= 0 → 原图返回`
  （必须早退：否则尺寸换算会算出 0×0 角标并把底图抹掉）。

**消费端**（全部 3 处调用点）：
`desktopiconbutton.cpp`（收纳盒 / 桌面镜像图标）、`desktopmirrorwindow.cpp` ×2（Dock 的两条布局路径）。

**热更新**（新增 `DesktopScanner::clearIconCache()`）：

| 窗口 | 做法 |
|------|------|
| 收纳盒 / 网格窗 | `IconGridWindow::reloadShortcutArrowMode()`：清进程内图标缓存 → 逐个按钮清空 `item().icon` 并重新入队（异步分批取图，不卡 UI） |
| Dock | 清缓存 → `m_entriesDigest.clear()` → `refresh()` |

**🚨 两个必须的点**：
1. `loadIconNow()` 只在 `item.icon.isNull()` 时才取图 —— **不清空 `item.icon` 的话，它会认为"已经有图了"，纹丝不动**。
2. Dock 不能只调 `refresh()`：它对「条目指纹未变」会直接 return（自激循环兜底），而改外观设置恰恰不改变任何条目 ——
   所以必须先清指纹，否则等于什么都没做。

## ④ 收起后，鼠标移动到标题自动展开 `Appearance/autoExpandOnHover`

**口径**：**收起状态下**，鼠标移到标题栏的折叠/展开按钮上即自动展开（等于替用户点一次）；
取消勾选则必须自己点击。

**落点**：`IconGridWindow::eventFilter` 与 `SidePanelWidget::eventFilter` 各加一支
`watched == m_moreBtn && event->type() == QEvent::Enter && 处于收起态` → `toggleGrid()` / `toggleCollapse()`。
两个折叠按钮都补了 `installEventFilter(this)`。

**🚨 判定点（刻意收窄）**：
- **只认折叠按钮，不做"整条标题栏 hover"**。收起后整窗就只剩这条标题栏，
  若整条都算"触发展开区"，鼠标随手划过屏幕碰到盒子就会弹开 —— 那是比"多点一次"更烦的体验。
- 用 `QEvent::Enter` 而非 `QEvent::HoverEnter`：后者需要 `WA_Hover` 才发，
  若某天按钮样式表里没有 `:hover` 规则就会静默失效。
- 关闭时（默认）第一句就短路，零额外开销。
