## 一、需求与澄清

用户截图圈出两根折叠条：左边**收纳盒窗口**（分类名「快捷方式」）、右边**桌面助手面板**，
要求「给添加一个自动对齐（格子对齐）功能」。

因「对齐」有歧义（窗口位置吸附 / 窗口互相吸附 / 一键排列 / 盒内图标整理），先问了一次。
用户**多选**了两项：

| 选项 | 用户选择 |
|---|---|
| 窗口吸附网格（拖动松手吸附到固定格子） | ✅ |
| 窗口互相磁吸（与其它盒子/面板边缘自动贴合） | ✅ |
| 一键排列整齐（加个「自动对齐」按钮） | ✖ 未选 |
| 盒内图标整理（重排盒内图标） | ✖ 未选 |

因此本次**只做拖动时的位置吸附**：磁吸 + 网格，不加按钮、不动盒内图标排布。

---

## 二、设计：磁吸优先、网格兜底

拖动窗口的每一帧算一次最终位置：

```
自由坐标 raw  ──► ① 窗口磁吸（其它挂件窗口 / 屏幕工作区的对齐线，阈值 8px）
                      │ 命中 → 用磁吸值（该轴）
                      ▼ 未命中
                 ② 网格吸附 → origin + round((raw-origin)/step)*step
```

- **磁吸优先**的理由：磁吸是"我要跟这个窗对齐"的明确意图；网格只是"别摆得太乱"的兜底。
  两者同时命中时取距离更小的那个，视觉上最跟手。
- 每个候选矩形对**每个轴算 5 种配对**：左-左、右-右、右贴左外侧、左贴右外侧、中心-中心
  （纵轴同理）→ 既能"贴边对齐"也能"居中"，覆盖常见的对齐诉求。
- **阈值 8 逻辑像素**。Qt 的逻辑像素已按 DPI 归一，任何缩放比下手感一致 —— **不再乘 DPR**。
- 候选选中用严格小于比较，结果稳定、不会在两线之间来回跳。

## 三、网格 = 一根折叠收纳盒的高度（44 逻辑像素）

> ⚠️ **本节的"原点 (0,0)"与"格子线 0/44/88…"已被后续修订推翻**：
> 12:51 加入**顶部留白**，12:57 定为 **10px** —— 网格原点改为 `(0, WindowSnap::topMargin())`，
> 格子线现为 **10 / 54 / 98 …**（步长仍是 44）。详见
> `自动对齐-顶部留白-实施报告-2026-09-24.md`。本节以下只保留"步长为什么是 44"的推导过程。

> **2026-09-24 12:40 修正**：初版网格沿用 Windows 桌面图标间距，实测本机为 **76×101 物理像素**，
> 垂直 101 的跳格过大。用户随后指定「离 dock 桌面顶部，约半个收纳盒（折叠）的距离，约 45 逻辑像素」
> → 网格步长改为 **`Theme::collapsedHeight()`（44）**，两轴正方格子，原点固定 (0,0)。

量取过程（都是直接问系统，不靠猜）：

- `LVM_GETITEMSPACING` = **76×101** 物理像素；DPR = 1.0（1920×1080，`GetDpiForWindow` = 96）；
- `SHELLDLL_DefView > SysListView32` 的窗口矩形与客户区都是 `(0,0,1920,1080)` → 桌面网格原点本就是 (0,0)；
- 用 Pillow 量用户截图里那根折叠条：深色行 **y=6..49 → 高 44 px**，与 `Theme::collapsedHeight()` 完全一致。

所以「约 45 逻辑像素」＝ **一根折叠收纳盒的高度**。取它当格子有三个好处：
格子线落在 **0、44、88、132…** 上；折叠态细条能**一格一根地贴在一起堆叠**（间距正好等于自身高度）；
跳格幅度从 101 降到 44，拖动明显更跟手。

`m_gridStepX/Y`（桌面图标间距）仍保留，但**只服务 Dock 内部图标吸附**，不再影响窗口对齐。

> `desktopmirrorwindow.cpp` 初版曾在这里发布桌面网格，修正后**已撤回**（否则 76×101 会覆盖 44），
> 该文件与 `windowsnap` 已无耦合。

关键实现注意：

- 🚨**每帧从当前鼠标位置重算自由坐标**（`event->globalPos() - m_dragPos`），
  **绝不在已吸附坐标上累加** —— 否则窗口一旦吸附就"粘住拖不动"。
- 🚨`FenceBox` 的坐标系是**父容器的局部坐标**（不是屏幕坐标）：磁吸候选取 `parentWidget()->rect()`
  与同父兄弟盒子，网格原点用 `gridOrigin() - parent->mapToGlobal(0,0)` 换算，吸附后再走原有的
  `qBound` 夹取，保证与顶层窗口吸的是同一套格子、不错位。
- 只吸附**位置**；缩放窗口不吸附尺寸（用户未要求盒子贴合格子尺寸）。

## 五、使用方式

- 拖动**收纳盒**或**桌面助手**：靠近别的盒子 / 面板的边或中心线（8px 内）会被"吸"过去；
  没有任何可对齐目标时，落在网格格子上（从桌面顶部起每 **44** 逻辑像素一格 —— 正好一根折叠条的高度）。
- **按住 Alt 拖动 = 临时关闭自动对齐**（想精确定位时的逃生口）。
- 收起态的细条同样生效（拖动逻辑与展开态共用）。
- 发现途径：鼠标停在收纳盒标题栏 / 桌面助手标题上，有 tooltip 说明这套规则。
