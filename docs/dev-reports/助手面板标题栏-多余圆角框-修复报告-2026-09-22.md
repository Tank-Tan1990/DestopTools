# 助手面板标题栏「多余圆角矩形框」修复报告

- 日期：2026-09-22
- 用户口径（截图红框，位于桌面助手面板标题栏最右侧）：**「红框内的菜单背景，圆角矩形框，去掉」**
- 结论：已修复，编译通过，等用户亲自实测。

---

## 一、现象

桌面助手面板（`SidePanelWidget`）标题栏最右侧，除 4 个功能按钮外，额外画出了一个
**圆角矩形框**（约 110~130 px 宽、比按钮略高、带渐变底与一圈青色描边）。
「悬停显示」模式下按钮被收起后，这个空框尤其显眼 —— 也就是用户红框圈住的东西。

## 二、根因（Qt 样式表会向子控件传播）

问题出在**上一轮为「悬停显示」新加的定宽容器 `m_menuBtnBox`**：

- `setupTitleBar()` 与 `applyTheme()` 两处给 `m_titleBar` 设的样式表都是**无选择器**写法：

  ```css
  background: qlineargradient(x1:0,y1:0,x2:1,y2:0,stop:0 rgba(17,26,46,1.0),stop:1 rgba(17,26,46,1.0));
  border-top-left-radius: 16px; border-top-right-radius: 16px;
  border-bottom: 1px solid rgba(34,211,238,0.12);
  ```

- Qt 的样式表**会传播到子控件**：无选择器的规则等价于对标题栏的**全部子控件**都匹配一遍。
  - 子控件若**自带样式表**（搜索框 `QLineEdit`、4 个 `QToolButton`）→ 用自身规则盖掉，看不出问题；
  - 子控件若是**裸 `QWidget`**（新加的 `m_menuBtnBox`，只为定宽占位而建，没有任何样式）→
    **白捡一份"渐变底 + 上圆角 + 青色下边线"**，于是一个多余的圆角矩形框被画了出来。

尺寸也吻合：框高 = 标题栏高 − 上下 margin(4+4)，框宽 = 4 个按钮宽 + 3 个间距。

## 三、改动（只 1 个文件，未动头文件）

`DestopTools/sidepanelwidget.cpp`，三处串行编辑：

| # | 位置 | 改动 |
|---|------|------|
| ① | `setupTitleBar()` 构造标题栏处 | `titleBar->setObjectName("sidePanelTitleBar")`，样式表套 `QFrame#sidePanelTitleBar { … }` |
| ② | `applyTheme()` 刷新标题栏处 | `m_titleBar` 同款加选择器（**必须同改**，否则 applyTheme 一跑又变回"往子控件传播") |
| ③ | 定宽容器创建处 | 显式 `setObjectName("sidePanelMenuBtnBox")` + `QWidget#sidePanelMenuBtnBox { background: transparent; border: none; }`，并留注释：它只负责占位，**不能有任何背景/边框** |

**风险核对（先做后改）**：确认 `Theme::toolButtonStyle()`、`Theme::lineEditStyle()` **都自带 `background`**，
所以把父规则限定成 `QFrame#…` 之后，这些子控件不会失去底色（否则会连带出现别的黑框）。
标题栏的直接子控件全都自有样式或已显式透明，限定选择器不会波及它们。

## 六、可复用的结论（已写入项目记忆）

> 给某个部件设样式表**必须带选择器**（`QFrame#objName{…}` + `setObjectName`）。
> 无选择器的规则会传播到所有子控件 —— 自带样式表的子控件会盖掉，但**裸 `QWidget` 子控件会白捡背景/边框/圆角**，
> 凭空显出多余的框。今后**新增任何装饰性容器/包装件（布局占位、对齐壳）都照此办**。
