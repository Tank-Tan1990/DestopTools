> 红框中的选项框功能是（收纳盒中的这些分类），**使用鼠标左键点击切换**。

即：设置中心 → 外观设置 → **分区标签切换** 这一组单选，管的是**收纳盒/桌面整理窗顶部那排分类标签**
（快捷方式 / 目录 / 文档 / 压缩 / 图片 / 其它 / 网址）的切换方式，方式是**鼠标左键点击**。

| 场景 | 结果 |
|---|---|

| 按下后带 2px 微抖再松开 | **能切换**（不会被"标签拖拽排序"吃掉） |
| 鼠标悬停在标签上 | **不切换** |


**只有设置中心自己在读写在自娱自乐 —— 产品里没有任何一处消费它。**

结论：
1. 「**点击切换**」能工作，但那**不是这个设置的功劳** —— 历史实现本来就是左键点击，看着像"生效"；
2. 「**悬停切换**」**从来没实现过**，勾了完全没反应（08-20 从下拉框改成单选组时只做了 UI）；
3. 所以这一组选项此前是**空设置**。

## 三、改动（只动这一项，其它外观一律未动）

| 文件 | 改动 |
|---|---|
| `icongridwindow.h` | 新增 `loadTagSwitchMode()` / `applyTagSwitchModeToTabs()` / `activateCategoryTab()` / `startHoverSwitch()`；新增成员 `m_tagSwitchMode`、`m_hoverSwitchTimer`、`m_hoverPendingTab`（`QPointer`，标签重建后自动置空，不会野指针） |
| `icongridwindow.cpp` | ① 构造期 + **每次窗口显示时**读取 `Appearance/tagSwitchMode`；② `buildTabs()` 末尾把模式下发到标签按钮；③ `onCategoryTabClicked()` 改为调用统一的 `activateCategoryTab()`（点击/悬停共用同一份切换动作，杜绝两处逻辑漂移）；④ `eventFilter()` 增加 `HoverEnter` 分支；⑤ `showEvent()` 重读设置 |
| 设置项语义 | `0 = 点击切换`（默认，也即你当前的值）→ **只有左键点击标签才切换，鼠标划过绝不切换**；`1 = 悬停切换` → 鼠标移到标签上即切换 |

实现要点：

- **默认模式零成本**：`HoverEnter` 分支第一句就是 `m_tagSwitchMode == 1`（比一个 int），
  默认模式下整段短路 —— 鼠标划过不可能切换分类，也不会给事件过滤路径增加任何开销。
- **悬停切换带 140ms 防抖**：否则鼠标划着扫过整条标签栏会连着 `rebuildGrid()` 7 次
  （每个标签一次），肉眼可见网格反复重建。防抖期间只保留"最后一个落点"，停稳才切。
- **生效时机**：设置中心页面自己写着"重启后生效"；此外窗口每次 `show()` 都会重读一次，
  所以**关掉再打开收纳盒窗口也立即生效**，不必重启程序。
