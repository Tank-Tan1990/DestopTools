# 拖框建收纳盒 —— 就地确认弹框（实施报告）

日期：2026-09-24 ｜ 产物：`DestopTools\release\DestopTools.exe`（1,329,664 B @ 03:14:56）

## 需求
桌面空白处拉框创建收纳盒时，**不要立刻生成**，先在**刚画出的那个框的位置与大小**上弹一个确认层（视为"框原地变成确认层"）；确认层的动作按钮为「创建收纳盒」（带 `new_box` 图标）＋「取消」，点确认才真正落成收纳盒。

## 实现

### 1. `GlassMessageBox` 扩展出通用确认框
```cpp
static int confirm(QWidget* parent, const QString& title, const QString& text,
                   const QString& okText, const QString& cancelText = QString(),
                   const QString& okIconName = QString(), const QRect& frameRect = QRect());
```
- `information()` / `warning()` 行为完全不变（内部 `m_okText` 为空时仍走原来的单个固定 `OK` 按钮分支）。
- **`frameRect` 非空 → 就地定位**：
  - 尺寸 `setFixedSize(qMax(360, w), qMax(180, h))`（小于卡片最小需求时退回 360×180，否则 48px 图标＋文字＋按钮会被挤爆）；
  - 位置 `move(frameRect.topLeft())`；
  - 整体夹进 `QGuiApplication::screenAt(center)` 的 `availableGeometry()`，贴边画框时确认层不会有一半在屏幕外。
- 卡片内容（图标＋文字）在大尺寸下**垂直居中**（`addWidget(..., Qt::AlignVCenter)`），大框时留白均匀。
- 确认按钮样式走紧凑 padding 版（`padding: 2px 16px; border-radius: 8px`），并过 `Theme::applyTokens` → 跟随「盒子使用圆角」开关；图标 `Theme::icon("new_box")`（16×16）。

### 2. 接入点：`MainWindow::createBoxFromDockRegion()`
在算名称 / 建窗口**之前**先确认；用户取消则 `return`，桌面保持原样（框已消失、选中集合未动）：
```cpp
const QString confirmBody = shellPaths.isEmpty()
    ? QStringLiteral("将在所选区域创建一个空的收纳盒。")
    : QStringLiteral("将在所选区域创建一个收纳盒，并把框内的 %1 个图标移入其中。")
          .arg(shellPaths.size());
if (GlassMessageBox::confirm(this, QStringLiteral("创建收纳盒"), confirmBody,
                             QStringLiteral("创建收纳盒"), QStringLiteral("取消"),
                             QStringLiteral("new_box"), globalRect) != QDialog::Accepted) {
    return;
}
```

### 3. 上下文安全性（为什么这里可以跑模态 exec）
`endRubber()` 只从**事件循环**里被调用：`rubberTick` 的 `QTimer::timeout` / Qt 鼠标事件 / 钩子路径的 `QTimer::singleShot(0, w, …)` 转发 —— **不在 `WH_MOUSE_LL` 回调栈内**，因此不会触发低级钩子的超时移除，也不会重入画框（`endRubber` 幂等，且 `m_rubbering / m_rubberRect` 已复位）。
