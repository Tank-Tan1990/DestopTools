# 桌面备份 · 「添加备份后设置中心消失、其他窗口点不动」修复报告

日期：2026-09-24 02:43
产物：`DestopTools\release\DestopTools.exe` = 1,316,352 B @ 2026-09-24 02:43:02（`NMAKE_EXIT=0`，打包 149 文件 / 67.4 MB）

## 一、现象
点「添加备份」→ 备份卡刷新出来了，但**设置中心整个窗口消失**；同时程序仍处于模态状态 → 其他窗口全部点不动（等于被一个"看不见的对话框"锁死）。

## 二、根因
上一轮为了修「新备份卡不重绘」，把截屏隐身从 Win32 `::ShowWindow(SW_HIDE)` 改成了 **Qt 层 `this->hide()` / `this->show()`**。但设置中心这个窗口是**三合一**的：

| 属性 | 来源 |
|---|---|
| 无边框顶层窗口 | `Qt::FramelessWindowHint \| Qt::Window \| Qt::NoDropShadowWindowHint` |
| 透明背景 | `setAttribute(Qt::WA_TranslucentBackground, true)` |
| 应用级模态 | 由 `dlg.exec()` 拉起 |

`hide()` 会让 Qt **丢弃/重置透明后援缓冲**，`show()` 回来时窗口可能整块 alpha=0（视觉上完全消失）；而 `exec()` 的**模态循环不会因为 hide 而退出** —— 于是变成「面板看不见 + 模态还在挡所有输入」，正是用户看到的死锁状态。

> 为什么前几版都不好：`hide()+QEventLoop`＝模态循环假死；`::ShowWindow(SW_HIDE)`＝OS 级隐藏、Qt 不知情，show 后 QScrollArea 缓存失效、新卡不重绘。

## 三、修复（`settingcenterdialog.cpp` · `createBackupNow()`）
截屏期间**完全不碰窗口可见性**，只把本窗移出屏幕：

```cpp
// 截屏期间【绝不 hide()/show() 本窗】，只把本窗「移到屏幕外」
const QPoint savedPos = this->pos();
this->move(-32000, -32000);
QApplication::processEvents();
::Sleep(120);                     // 等 DWM 重新合成
... BitBlt + CAPTUREBLT 抓屏 ...  // 本窗不在屏幕内 → 不进图；其他程序照常进图
this->move(savedPos);             // 只 move 不改尺寸，移回原位
this->raise();
this->activateWindow();
this->update();
```

- 窗口自始至终"**可见且是同一个前台模态窗**"：Qt 的可见性 / 模态 / z 序状态**零改动**，不会丢位置、不会再假死；
- 截屏结果与要求一致：**不含设置中心**、**含其他程序**；
- 卡片即时刷新那套（`invalidate/activate + adjustSize + updateGeometry + viewport update + repaint + processEvents`）保留，点完备份卡片立即可见；
- 模态按你的要求**保持不动**（`exec()` 未改）。

## 四、三条路对比（沉淀结论）
| 隐身方式 | 结果 |
|---|---|
| `hide()` + 嵌套 `QEventLoop` | ❌ 模态循环仍跑 → 全程序假死 |
| Win32 `::ShowWindow(SW_HIDE)` | ⚠️ OS 级隐藏、Qt 不知情 → show 后新卡不重绘 |
| **`move(-32000,-32000)` 移出屏幕** | ✅ 唯一同时满足「不进截图 + 面板不消失 + 卡片即时刷新」 |

通用判据：**任何"临时隐身"都不要动窗口的可见性**（尤其透明 / 模态窗口）。
