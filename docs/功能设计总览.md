## 一、项目定位

**DestopTools 是一款 Windows 桌面图标整理与收纳工具（仿 360 桌面整理）**，基于 Qt 5.14.2 (msvc2017_64) + Win32 API 构建。核心思路：接管原生桌面图标（隐藏系统图标层），在自有分层窗上自绘图标，并提供"收纳盒 / 分类 / 备份 / 待办 / 主题"等一整套桌面治理功能。

技术特征（决定后续所有设计走向）：
- **无边框 + 分层窗（Layered Window）**：Dock、收纳盒、助手面板均为 `FramelessWindowHint` + `WA_TranslucentBackground` 的顶层窗，自己实现拖动与 z 序守卫。
- **系统级低级钩子**：`WH_MOUSE_LL` / `WH_KEYBOARD_LL` 用于 F2/Delete 与双击隐藏等全局交互；鼠标卡顿根治后鼠标钩子改为 **Raw Input**（`WM_INPUT`）。
- **Win32/Shell 深度集成**：原生桌面图标接管、回收站动态图标、原生右键菜单、COM 取图标、BitBlt 截屏等。

## 三、功能设计清单（按子系统）

> 每条 = 功能名 ｜ 设计意图 ｜ 关键实现要点 ｜ 对应报告

### A. 桌面图标整理层（Dock / DesktopMirrorWindow）

1. **原生桌面接管与隐藏**
   - 将原生桌面图标 `attachToDesktop`，owner 双保险（`GWLP_HWNDPARENT=SHELLDLL_DefView` + `WS_EX_NOACTIVATE|WS_EX_TOOLWINDOW`），去 owner 路线封禁。快路径：owner 已是 DefView 直接 return。
   - 报告：`鼠标移动卡顿-修复实施报告-2026-09-21.md`、MEMORY「核心约束」

2. **自绘图标分层窗（Dock）**
   - 铺满主屏、`SetWindowPos(HWND_BOTTOM)` 压在最底的分层窗；自绘全部桌面图标（图标∪标签并集，4px 间隙）。不订阅主题，样式全走全局 QSS。
   - 报告：`Dock拖入收纳盒-拖拽图标置顶浮层-报告-2026-09-22.md`

3. **图标取图与缓存**
   - `SHDefExtractIcon` 必须 `MAKELONG(large,small)`；**只认目标文件**（`effectiveTarget`）取图，填 `.lnk` 自身会掉到系统 48px 兜底；`g_iconCache` ≤2048 限容。
   - 报告：MEMORY「Win32/Shell」「编辑态/重命名」

4. **回收站动态图标**
   - CLSID `645ff040` 短路走 `recycleBinIcon`（SYSICONINDEX→SHIL_EXTRALARGE），不经缓存；`pollRecycleBinState` 1.5s 轮询、翻转才 `setIcon`。
   - 报告：MEMORY「Win32/Shell」

5. **内联重命名（F2）**
   - 提交仅 Enter/Esc/点框外三通道；新建项自动弹框（`applyAutoRename`，按会话事实入队，非按名字形状）；改名后 `item.icon=QIcon()`。Dock/网格两侧状态机对称修改。
   - 报告：`Dock启动期自动重命名-修复报告-2026-09-22.md`、MEMORY「编辑态/重命名」

6. **删除（拖到回收站）**
   - 图标矩形相交 ≥1/4 即删除；唯一通道 `deleteDockItems` → `ShellOps::deleteToRecycleBin`（FOF_ALLOWUNDO|WANTNUKEWARNING）。
   - 报告：MEMORY「拖放语义」

7. **框选多选（橡皮筋）**
   - Qt + `WH_MOUSE_LL` 双通道汇同状态机，16ms 轮询推进，整组拖动以 `m_dragPrimary` 基准。
   - 报告：MEMORY「拖放语义」「快捷键/选中」

8. **跨窗口拖放（Dock↔收纳盒）**
   - 不走 QDrag（跨 NOACTIVATE 窗不可靠），靠 40ms 轮询转发指示线+光标；松手按位插入，先落顺序键再刷新。组 MIME 禁 `setUrls/setText`（防升级成系统拖放真落盘）。
   - 报告：`Dock拖入收纳盒-插入位指示与按位插入-报告-2026-09-22.md`、`Dock拖入收纳盒-拖拽图标置顶浮层-报告-2026-09-22.md`、`优化-收纳盒图标交换与Dock拖入-原地复用-2026-09-24.md`

9. **拖拽图标置顶浮层**
   - Dock 为最底层分层窗，拖到收纳盒上图标被遮；用 `DockDragGhost` 置顶浮层只画与收纳盒相交区（`WindowTransparentForInput`，绝不吃鼠标）。
   - 报告：`Dock拖入收纳盒-拖拽图标置顶浮层-报告-2026-09-22.md`

10. **双击空白隐藏桌面图标**
    - `WH_MOUSE_LL` 不送 `WM_LBUTTONDBLCLK`，自判双击（`GetDoubleClickTime`+`SM_CX/YDOUBLECLK`）；隐藏态仅内存、必须在 `layoutButtons()` 末尾重套，否则刷新冲掉。
    - 报告：`快捷操作-两项功能接通-实施报告-2026-09-24.md`

### B. 收纳盒（FenceBox / IconGridWindow）

11. **桌面收纳盒创建**
    - 空白拉框（≥48×36 逻辑像素）建盒，名称 `收纳盒N` 取未占用最小序号；框内图标走既有 `scheduleDockItemsIntoBox`。

12. **拉框建盒就地确认弹框**

    - 报告：`拖框建盒-就地确认弹框-实施报告-2026-09-24.md`

13. **分类标签页切换**
    - 点击切换（左键）/悬停切换（停稳 140ms）两种模式；消费端 `icongridwindow` 订阅 `settingChanged` 按 key 热更新（不重启即生效）。
    - 报告：`分区标签切换-接线修复报告-2026-09-21.md`、`分区标签切换-热更新修复报告-2026-09-22.md`、`分区标签切换-悬停选中态同步-报告-2026-09-22.md`、`分区菜单标签显示-接通报告-2026-09-22.md`

14. **盒内网格视图档位**
    - 大 96 / 中 48（默认）/ 小 32 / 列表四档；列表档整块自绘（`paintListMode`，QToolButton 无"图标贴左+文字紧随"布局）。
    - 报告：MEMORY「Win32/Shell」

15. **收纳盒局部刷新（关键性能设计）**
    - 只换顺序走 `tryReorderInPlace`/`reorderItemsInPlace`（不销毁重建按钮）；`setItems()` 回流走 `applyItemsDeltaInPlace` 增量；盒窗口顺序由窗口权威数据承载，防滞后数据"还原"用户排序。
    - 报告：`修复-分类切换卡顿与多选取消失效-2026-09-24.md`、`优化-收纳盒图标交换与Dock拖入-原地复用-2026-09-24.md`、`收纳盒交换位置-图标十几秒才出现-修复报告-2026-09-24.md`

16. **分类页缓存（切分类不刷新）**
    - park/adopt：切走换父到 `m_pageCacheHost`，装回显式 `show()`；命中＝逐页内容签名（顺序敏感）；上限 `qBound(8, size, 24)`。顺序变化走原地复用+重排（`HIT-RESORT`），禁判 stale 重建。
    - 报告：`分类切换-页缓存复用-报告-2026-09-22.md`、`分类切换-页缓存被绕开-修复报告-2026-09-22.md`、`修复-分类切换卡顿与多选取消-重新实施-2026-09-24.md`

17. **增删分类与新收纳盒一并处理**
    - 报告：`分类切换-增删分类与新收纳盒一并处理-报告-2026-09-22.md`

18. **收纳盒外观（边框/圆角/线框）**
    - 盒子显示边框只管最外层 `boxChrome`；外框与内容区圆角方角一致性；分类栏与图标区外线框消失修复。

### C. 分类系统（CategoryStore）

    - 报告：`桌面备份-真根因修复-两份配置与卡片刷新-2026-09-24.md`、MEMORY「桌面备份」

22. **360 式备份网格 UI**

## 六、设计铁律速查（动手前必读）

1. **主题两通道**：`border:` 一律 `alphaF`（恒定）、背景一律 `bgAlphaF`；背景字面量只有两种，全经 `applyTokens`。禁回退 `setWindowOpacity`。
2. **样式表必带 id 选择器**：`QFrame#objName{}`+`setObjectName`，防规则外溢到子件/兄弟类。
3. **圆角走 `Theme::radiusPx(base)`**，禁写死数字。
4. **菜单 `Theme::applyMenuStyle()`**；占位色唯一来源 `QPalette::PlaceholderText`。
5. **设置两段式**：构造/显示读一次 + `notifySettingChanged` 热更新；同页多对 RadioButton 各装 `QButtonGroup`。
6. **无边框顶层窗三件套**：flags + 错峰 raise + nativeEvent 清 `SWP_NOACTIVATE`。
7. **钩子路径禁同步文件 I/O**（走 DiagTrace）；物理→逻辑 `phys/dpr`；F2/Delete 闸门用 `lowLevelHooks().registered(token)`。
8. **分类页缓存**：park/adopt + 逐页签名复用；几何变化走 `relayoutGridForGeometry` 非 `rebuildGrid`。
9. **桌面备份两份 INI**（`DestopTools.ini`＋`categories.ini`）；截屏隐藏本窗只 `move(-32000,-32000)`。
10. **自动对齐**：磁吸优先网格兜底；顶部留白 10px 与网格步长解耦；拖动每帧重算自由坐标。
11. **日志统一开关**：仅 INI `[Diagnostics] traceEnabled`，默认 `false`（false＝trace.log 与 crash.log 都不写）。
